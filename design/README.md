# BodyCal design sources

Original-resolution composite references are now present in this directory. Route-to-source coverage is recorded in `MAPPING.md`, and values observed from the supplied references are recorded in `TOKENS.md`.

The design audit must produce a mapping from every implemented route to real filenames and extract colors, typography, spacing, radii, shadows, controls, icon rules, charts, camera, onboarding, and paywall patterns. Platform, responsive, localization, reduced-motion, and accessibility deviations should be recorded alongside that mapping.

Mapping a route does not by itself make it visually accepted. Each implemented screen still requires iOS and Android comparison captures plus accessibility, localization, responsive, and reduced-motion review.
